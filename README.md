📘 Daily Diary — Python and Agentic AI

👨‍💻 Training Domain: Python Programming & Agentic AI
📅 Duration: 4 Weeks
📝 Total Entries: 20 Days

⸻

📅 Week 1 — Python Fundamentals

🚀 Day 1: Introduction to Software Development and Agentic AI

Today, I was introduced to the training programme and its objectives. We discussed the basics of software development and how applications are planned, developed, and tested. The session also introduced agentic AI and how AI systems can perform tasks using tools and structured instructions.

🎯 Learning Outcome: I understood the basic software development process and the role of agentic AI in automating tasks.

🧠 Day 2: Python Memory and MVC Architecture

Today, we explored how Python manages objects and memory references. We discussed mutable and immutable objects and how variables refer to values in memory. We also learned about the Model-View-Controller (MVC) architecture and how it separates data, interface, and application logic.

🎯 Learning Outcome: I learned the importance of memory management and structured application design.

🗂️ Day 3: Containers, References, and Data Structures

The session focused on Python containers and data structures. We discussed lists, tuples, sets, and dictionaries and explored how references and copying affect data. We also examined how different structures are suitable for different programming problems.

🎯 Learning Outcome: I learned how to select appropriate data structures for storing and processing information.

🔄 Day 4: Loops, Modules, and Matrix Practice

Today, we studied loops, Python modules, and program execution. We practised using for loops, range(), dictionary iteration, and nested loops. A practical example involved representing a chessboard using an eight-by-eight matrix.

🎯 Learning Outcome: I improved my understanding of loops and learned how nested iterations can solve structured problems.

⚙️ Day 5: Operators, Conditions, and Coding Standards

We explored arithmetic, comparison, logical, assignment, membership, and bitwise operators. We also practised conditional statements and nested conditions using practical examples. The session introduced PEP 8 guidelines for writing clean and readable Python code.

🎯 Learning Outcome: I learned how operators and conditional statements control program behaviour and why coding standards matter.

📚 Day 6: Python Fundamentals Revision

Today, I revised the topics covered during the first week, including memory references, containers, loops, operators, and conditional statements. I reviewed small code examples to understand how different statements work together and identified topics requiring additional practice.

🎯 Learning Outcome: I strengthened my understanding of Python fundamentals and basic programming logic.

⸻

📅 Week 2 — Functions, Algorithms & OOP

🧩 Day 1: Functions and Flexible Arguments

Today, we learned about Python functions, parameters, return values, and variable scope. We explored default arguments and flexible arguments using *args and **kwargs. The session also introduced recursion and how functions can call themselves to solve problems.

🎯 Learning Outcome: I learned how functions improve code reusability and simplify complex tasks.

🔍 Day 2: Recursion, Searching, and Sorting

The session focused on algorithms and problem-solving techniques. We studied recursive functions, linear search, and bubble sort. We traced the execution of algorithms step by step to understand how elements are compared, searched, and rearranged.

🎯 Learning Outcome: I developed a better understanding of searching and sorting algorithms and their implementation in Python.

🏗️ Day 3: Object-Oriented Programming

Today, we explored object-oriented programming concepts, including classes, objects, attributes, and constructors. We discussed how the __init__() method initializes objects and how objects can represent real-world entities. We also examined relationships between objects.

🎯 Learning Outcome: I learned how object-oriented programming helps organise data and behaviour into reusable components.

🔗 Day 4: Class Methods and Linked Lists

We continued studying object-oriented programming and learned how methods operate on object data. The practical session introduced linked lists, including circular doubly linked lists. We discussed how nodes connect to previous and next nodes and how this structure can represent a music playlist.

🎯 Learning Outcome: I understood the basic structure of linked lists and their practical applications.

🚦 Day 5: Queues, Strings, and Slicing

Today, we explored queues and how they manage items in sequence. A toll-plaza example demonstrated how vehicles can be processed in an organised order. We also studied Python strings, indexing, slicing, and string immutability.

🎯 Learning Outcome: I learned how queues represent ordered processing and how string operations help manipulate text.

📝 Day 6: Algorithms and Data Structures Revision

I revised functions, recursion, searching, sorting, object-oriented programming, linked lists, queues, and string operations. I practised tracing program execution and considered situations such as empty collections and unsuccessful searches.

🎯 Learning Outcome: I improved my ability to apply programming concepts to practical problems and check for common errors.

⸻

📅 Week 3 — Databases, Web Apps & AI Integration

📂 Day 1: File Handling and Data Serialization

Today, we learned how Python programs read and write files. We explored file modes, the with open() statement, and handling CSV and JSON data. We also discussed virtual environments and making HTTP requests to communicate with external services.

🎯 Learning Outcome: I learned how to store data persistently and convert information into formats suitable for exchange between applications.

☁️ Day 2: MongoDB Atlas and Data Security

The session introduced MongoDB Atlas and connecting Python applications to a cloud database using pymongo. We discussed databases, collections, and document-based storage. We also explored SHA-256 hashing and the importance of handling sensitive information securely.

🎯 Learning Outcome: I understood the basics of cloud database connectivity and the importance of protecting stored information.

🗃️ Day 3: CRUD Operations and Streamlit Forms

Today, we studied CRUD operations: Create, Read, Update, and Delete. We explored how these operations can be implemented using database helper methods. We also learned how Streamlit forms, input fields, and buttons can create a simple interactive registration interface.

🎯 Learning Outcome: I learned how user interfaces interact with databases to store and manage information.

💬 Day 4: Chat Interfaces and Task Management

We explored how to create a chat interface using Streamlit. We discussed chat input components, message display, and session state for maintaining conversation history. We also examined how natural-language requests can be organised into structured task information.

🎯 Learning Outcome: I understood how interactive interfaces maintain context and convert user requests into structured data.

🤖 Day 5: OpenAI Function Calling

Today, we were introduced to function calling through the OpenAI API. We discussed defining tools with JSON schemas, sending requests to a model, interpreting tool calls, and executing the corresponding Python functions. We also learned why API keys should be stored securely rather than directly in source code.

🎯 Learning Outcome: I learned how AI models can connect natural-language instructions with predefined application functions.

🔧 Day 6: Application Integration and Revision

I revised file handling, JSON, HTTP requests, MongoDB, hashing, Streamlit, and OpenAI function calling. We discussed how these components can work together in an application, from accepting user input to processing requests and storing results.

🎯 Learning Outcome: I gained a clearer understanding of integrating interfaces, application logic, databases, and AI services.

⸻

📅 Week 4 — Advanced Python & Project Development

⚡ Day 1: Iterators, Generators, and Decorators

Today, we explored advanced Python concepts, including iterators, generators, and decorators. We learned how iter() and next() access items one at a time and how generators use yield to produce values. We also discussed decorators as a way to extend function behaviour.

🎯 Learning Outcome: I understood how iterators and generators manage sequences and how decorators support reusable functionality.

🛡️ Day 2: Collections, Exceptions, and Set Operations

The session covered multidimensional lists, indexing, slicing, and common list methods. We practised exception handling using try and except and explored set operations such as union, intersection, and difference. We also reviewed dictionary methods for accessing and processing data safely.

🎯 Learning Outcome: I improved my understanding of Python collections and learned techniques for handling runtime errors.

🔎 Day 3: Regular Expressions and Dashboards

Today, we studied regular expressions and their applications in text processing. We explored patterns for identifying information such as email addresses, phone numbers, and URLs. We also learned about Streamlit dashboard features, including navigation, metrics, charts, and dataframes.

🎯 Learning Outcome: I learned how regular expressions extract structured information from text and how dashboards present data clearly.

🌐 Day 4: Web Search APIs and Web Scraping

The session introduced retrieving information through web APIs and processing structured JSON responses. We also explored web scraping concepts using Python libraries such as Requests and BeautifulSoup. We discussed how HTML elements can be selected and their text extracted for further processing.

🎯 Learning Outcome: I gained an understanding of how Python applications collect and process information from online sources.

🧱 Day 5: Capstone Project Architecture

Today, we discussed the architecture of an AI-based task management and delegation project. The project combined concepts involving Streamlit, OpenAI function calling, MongoDB, and external services. We examined how dividing an application into modules makes its components easier to maintain and test.

🎯 Learning Outcome: I understood the importance of modular design and how different technologies can be combined to build an AI-powered application.

✅ Day 6: Final Revision and Project Review

On the final day, I reviewed the major concepts covered during the training programme, including Python fundamentals, algorithms, object-oriented programming, file handling, databases, web interfaces, APIs, and agentic AI. We discussed the importance of testing, documentation, secure configuration, and checking how different application components work together.

🎯 Learning Outcome: I consolidated my learning and developed a broader understanding of building, testing, and maintaining Python-based applications.
